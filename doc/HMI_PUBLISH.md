# HMI > Publish

**HMI > Publish** turns the open HMI project into a Windows installer for the
target PC. The installer holds this same app in a locked, run-only mode that
opens the project straight into Run, together with the `hmi-comms` PLC server.
It is built on whatever machine the editor runs on (Windows, Linux or macOS),
with no Windows machine and no wine.

## Publishing

1. Set up the runtime in **HMI > Application Settings > Runtime**:
   - **Window**: *Kiosk* (full screen, no taskbar; the default), *Full
     screen*, or *Window* at the target resolution.
   - **Exit**: *Exit shortcut* (Ctrl+Alt+Shift+Q; the default), *Exit
     shortcut and password*, or *Never* (shut Windows down to stop it). The
     password is stored in the project only as a salted SHA-256 hash.
2. Choose **HMI > Publish...**. The project is validated first, as
   **Validate Expressions** does; problems can be reviewed or published anyway.
3. Fill in the dialog:
   - **Product name** and **Version**: the name the installed program,
     shortcuts and Add/Remove Programs show, and the version (numbers
     separated by dots). The next publish suggests the next version.
   - **Publisher**: optional, shown in the exe's properties and Add/Remove
     Programs.
   - **Icon**: optional `.ico` for the exe, shortcuts and window.
   - **Install for**: *the user who installs it* (no administrator rights,
     `%LOCALAPPDATA%\Programs\<Product>`) or *all users* (administrator,
     `C:\Program Files\<Product>`).
   - **Desktop shortcut**, **Start with Windows**: optional shortcuts; a
     Start menu shortcut is always made.
   - **Compression**: *smaller installer* (solid LZMA, about 165 MB, a few
     minutes) or *faster build* (zlib, about 215 MB, under a minute).
   - **Save to**: Documents by default; **Browse** picks another folder.

The result is `<Product>-<version>-Setup.exe`. The options are saved with the
project (it is marked modified), so save it afterwards to keep them.

Devices are published as they are in the project. A simulator device keeps
simulating on the target PC; the dialog warns when the project has one.

## Installing on the target PC

- Run the installer, or install silently with `/S` (for example from a
  deployment tool). Installing a newer version over an older one upgrades it
  in place and stops the running runtime first.
- Uninstall from Add/Remove Programs, or silently with
  `"<install folder>\Uninstall.exe" /S`.
- The runtime keeps its settings and a log in `%APPDATA%\<Product>`
  (`logs\main.log`): startup, the project it loaded, device connection
  changes, exit attempts and renderer errors. The log is left in place on
  uninstall.

Kiosk mode stops the operator leaving the screen through the app, but not
Ctrl+Alt+Del or Windows-key shortcuts. For a fully locked station use Windows'
own assigned access (kiosk) settings as well.

The installer and the installed program are not code-signed, so Windows
SmartScreen warns on first run until signing is added.

## How it works

- The package installs the Windows app from a prebuilt *template*:
  - a Windows editor uses its own install folder;
  - a Linux or macOS editor ships one in `resources/runtime/win-x64`;
  - a source checkout uses `dist-win-runtime/win-unpacked`, built by
    `npm run build-win-runtime`.
- The installed exe is renamed after the product, and resedit rewrites its
  version resource and, optionally, its icon.
- `resources/hmi-runtime/{runtime.json, project.ahmi}` in the install
  folder switches the app into run-only mode (`src/main/runtime/RuntimeMode.js`,
  `js/hmi/HmiRuntimeApp.js`):
  - it gets its own userData folder;
  - there is no updater, menu or file access;
  - the window closes only as the exit policy allows.
- Installers are compiled with the NSIS 3.0.4.1 bundle that electron-builder
  uses, shipped in `resources/nsis` (`npm run fetch-nsis` in a source
  checkout). The script is generated by `src/main/publish/NsisScript.js`.
- To try run-only mode without installing, point the app at a folder holding
  a `runtime.json` and the project:
  `HMI_ENV=dev npx electron . --hmi-runtime <folder>`.
